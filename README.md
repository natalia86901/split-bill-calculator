# Split Bill Calculator

A simple and clean web app to split bills between multiple people, with an optional tip selector.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- [SweetAlert2](https://sweetalert2.github.io/) — for error pop-up alerts
- Google Fonts (Montserrat, Dancing Script, Roboto)

## Features

- Enter a bill amount and number of people to split it between
- Optionally add a tip (10%, 20%, 30% or no tip)
- Calculates and displays the bill, tip, and total per person
- Validates inputs and shows an error alert for missing or invalid entries
